# Changelog

Every mainnet deploy of the program is listed here with its commit, the verified build hash and what changed. Breaking changes to account layouts, instructions or events are announced here at least one NFL week before they are deployed.

## Unreleased

- SDK chain layer (`@mybarpool/shared`): Codama-generated client, instruction helpers, reads, event subscriptions, transaction preparation for v1 and legacy formats.
- Program complete and frozen for the external audit (build plan Steps 2–8): config and admin; game records, kickoffs and scores; pools, buying, sponsorship and creator limits; the Entropy draw against the platform's own deployment with the commit binding; settlement and fees; returns, splits, cancellation, reclaim and close; private pools (`link` with a gate key, `allowlist` with a Merkle proof, PROGRAM §6.4). 26 instructions, 6 account types, 24 events, 65 errors; account layouts and event schemas frozen by a snapshot test; a fuzzer seeded from the unit suite runs in CI; `AUDIT-READINESS.md` is the entry point for reviewers. No mainnet deployment yet.
- Shared math (build plan Step 1): `packages/shared` gains the pure core of the SDK. Box labelling (index 0–24 ↔ label 1–25, the only place that conversion happens); the reference implementations of the program's box assignment, axis shuffle and winner (PROGRAM §6) with shared test vectors in `src/vectors/` that the program's own tests load; the canonical game key and `GameRecord` seeds (5-byte little-endian key: season u16, week, home, away); the 32-team table; price ladders; fees, prize pool, quarter prizes and dust in `bigint` base units exactly as PROGRAM §5; display formatting; the score-source ID map and sponsor directory shapes. One runtime dependency, `@noble/hashes` 2.4.0.
- Scaffold (build plan Step 0): Anchor 1.2.0 workspace with an empty `programs/mybarpool` that builds as SBPFv3, Mollusk unit tests and a committed compute-unit table; `packages/shared` as an empty TypeScript package on `@solana/kit` 8 with build and tests; Surfpool 1.6.0 as the localnet, forking mainnet at 200 ms slots, with a first test that reads the real Entropy program; CI for all of it plus the Solana Foundation's reusable verifiable-build workflow (deploy wired, off) and OtterSec's anchor-lints. Toolchain pinned in `rust-toolchain.toml`, `Anchor.toml` and `package.json`.
- Design published: rules, fees, lifecycle, randomness, trust model, private pools, screens.
- Program specification published (`docs/PROGRAM.md`): accounts, instructions, events, errors, algorithms. Sponsorship (add to a pool's prizes before kickoff, no fee) added to the rules.
- Program and SDK: in development. No mainnet deployment yet.
